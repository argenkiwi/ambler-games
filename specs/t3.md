# Tic-Tac-Toe (t3)

This program is a Tic-Tac-Toe game where the user plays against the computer on a 3x3 board. The program randomly assigns 'X' or 'O' to the player and computer, prints the board, alternates turns between the player and computer (with AI), checks for win or draw conditions after each move, and announces the final result.

## Shared State

The shared state tracks all game data:

- `board: (string | null)[]` — The 3x3 board as a 9-element array. `null` means empty; `"X"` or `"O"` means occupied.
- `playerChar: string` — The character assigned to the player (`"X"` or `"O"`).
- `computerChar: string` — The character assigned to the computer (`"X"` or `"O"`).
- `move: number` — The last move number entered (1-indexed, corresponding to the classic tic-tac-toe numbering 1–9).
- `result: string` — The final result message (`"You win!"`, `"You lose!"`, or `"Deuce!"`).

## Steps

### Start
- Randomly assigns `"X"` or `"O"` to the player (the other character goes to the computer).
- Initializes the board as all empty (`null` in each cell).
- Prints the assignment message: `Player is [X] and computer is [O]` (or vice versa).
- Transitions to `printBoard`.

### Print Board
- Displays the current board state as a formatted 3x3 grid using pipes and dashes, matching the Python script's output style.
- Cells containing `"X"` or `"O"` display the character; empty cells display a space.
- Transitions to `playerMove`.

### Player Move
- Prompts the player to enter a move number from 1 to 9.
- Validates that:
  - The input is a number between 1 and 9.
  - The corresponding board cell is empty.
- If invalid, prints an error message and stays on `playerMove` (loops until valid).
- On valid input, stores the move number in state and transitions to `playerPlace`.

### Player Place
- Places the player's character on the board at the 0-indexed position (`move - 1`).
- Checks if this move results in a win for the player.
- If the player won, sets `result` to `"You win!"` and transitions to `printFinalBoard`.
- If the player did not win, transitions to `computerMove`.

### Computer Move
- Uses a priority-based AI strategy:
  1. **Try to win**: Check each empty cell and place a trial move; if it results in a win for the computer, choose that cell.
  2. **Block the player**: Check each empty cell and place a trial move with the player's character; if it would result in a win for the player, choose that cell to block.
  3. **Strategic positions**: Prefer center (5), then corners (1, 3, 7, 9), then edges (2, 4, 6, 8).
- Places the computer's character on the selected cell.
- Checks if this move results in a win for the computer.
- If the computer won, sets `result` to `"You lose!"` and transitions to `printFinalBoard`.
- If the computer did not win, transitions to `checkGame`.

### Check Game
- Checks if the board is full (no empty cells remain).
- If the board is full and no one has won, sets `result` to `"Deuce!"` and transitions to `printFinalBoard`.
- If the board still has empty cells, transitions back to `printBoard` for the next round.

### Print Final Board
- Displays the final board state (same format as the regular board print).
- Transitions to `end`.

### End
- Prints the final result message with decorative formatting:
  - `"You win!"` → `=== You won! ===`
  - `"You lose!"` → `=== You lose! ===`
  - `"Deuce!"` → `=== Deuce! ===`
- Terminates the program (transitions to `null`).

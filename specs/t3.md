# Program Specifications

Tic-Tac-Toe against the computer on a 3x3 board whose cells are numbered 1 to 9, row by row. The player always moves first, with X or O assigned at random.

## Nodes

### T3 Start
- Initial node of the application.
- Clears the board and gives the player X or O at random; the computer gets the other mark.
- Prints who has which mark.
- Transitions to `T3_PRINT_BOARD`.

### T3 Print Board
- Prints the board as a grid, with a space for each empty cell.
- Transitions to `T3_PLAYER_MOVE`.

### T3 Player Move
- Asks the player for a cell from 1 to 9.
- If the cell exists and is empty, it records the move and transitions to `T3_PLAYER_PLACE`.
- Otherwise it prints an error and transitions back to `T3_PLAYER_MOVE`.
- If input has ended, the program terminates.

### T3 Player Place
- Puts the player's mark in the chosen cell.
- If that completes a line, it records "You win!" and transitions to `T3_END`.
- Otherwise it transitions to `T3_CHECK_GAME`.

### T3 Check Game
- Checks whether the board is full. Because the player moves first, only the player's move can fill it.
- If it is full, it records "Deuce!" and transitions to `T3_END`.
- Otherwise it transitions to `T3_COMPUTER_MOVE`.

### T3 Computer Move
- Chooses a cell for the computer: one that wins if there is one, else one that blocks the player's win, else the first free corner (1, 7, 3, 9), then the centre, then an edge.
- Puts the computer's mark there.
- If that completes a line, it records "You lose!" and transitions to `T3_END`.
- Otherwise it transitions to `T3_PRINT_BOARD`.

### T3 End
- Prints the final board and the result, and terminates.

## Shared State

The shared state consists of:
- `board`: the nine cells, each holding a mark or empty.
- `playerChar`: the player's mark, X or O.
- `computerChar`: the computer's mark.
- `move`: the cell the player last chose.
- `result`: the final result, once the game is over.
